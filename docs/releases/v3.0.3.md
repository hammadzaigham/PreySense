# PreySense v3.0.3

## Tuning

- Apply/Save with GPU limits off no longer changes Acer mode (CPU/PROCHOT-only writes).
- Mode restores still switch Acer mode, then apply saved CPU/GPU/PROCHOT for that mode.
- Reset restores MSR 0x610 to calibrated static floors when live MSR is above them, then writes factory MMIO limits and clears all apply switches.
- GPU profile apply waits **2 s** for the EC before activating the target mode (CPU-only applies stay undelayed).
