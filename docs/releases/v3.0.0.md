# PreySense v3.0.0

Simple guide to what changed in v3.

## Before you upgrade

1. **Uninstall your previous PreySense version** first. Do not copy v3 over an old install.
2. **OpenCore is gone.** v3 does not use OpenCore, EFI patches, or SSDT overlays. If an older PreySense install put OpenCore on your ESP, remove that OpenCore PreySense setup before using v3.
3. Run the new `PreySense.exe` **as administrator**.

## What’s new

### Driver tuning (replaces OpenCore)

- Custom CPU and GPU power limits now use a **bundled CPU driver**.
- No OpenCore install, no ACPI table patching, no PreySense WMI SSDT.
- Turn on **Enable Tuning**, edit a mode, then **Apply** or **Save**.

### Per-mode power controls

For each Acer mode (Eco, Quiet, Balanced, Performance, Turbo) you can set:

- CPU **PL1**, **PL2**, and **Tau**
- GPU **Delta**, **Dynamic Boost**, and **platform power offset**

Saved modes apply automatically when you switch modes, at startup, and after wake (when tuning is enabled).

### Factory calibration

- When tuning is first set up, PreySense reads factory defaults once and stores them in `preysense.json`.
- **Reset** returns a mode to those captured factory values.
- Your custom values stay null until you explicitly **Save**.

### PROCHOT offset

- Optional global temperature offset under Enable Tuning.
- Apply/Save can write it with the rest of the profile when the switch is on.

### Overlay and clocks

- Overlay metrics are selectable.
- GPU **Active** and **Effective** clock are separate choices.
- CPU requested voltage (VID) is available through the bundled driver.

### Cleaner app

Removed from v3:

- OpenCore / ACPI override path
- DTS audio windows
- Per-game profile launcher
- Old PawnIO-based CPU path

Core Predator features remain: modes, fans, lighting, display, battery, tray, languages.

## How to use tuning

1. Open **Tuning**.
2. Enable tuning.
3. Pick a mode, set the values you want.
4. **Apply** to test, or **Save** to keep them.
5. Switch modes as usual — saved profiles follow the mode.

## Notes

- Still developed and verified on **Predator Helios Neo 16S (`PHN16S-71-98RF`)**. Other models may work; not guaranteed.
- Wrong power or fan settings can cause throttling or instability. Use at your own risk.
