PreySense v2.4.0

## New features

- PawnIO CPU static power-limit control alongside dynamic MMIO limits, with MSR/MMIO readback verification.
- Automatic PawnIO installation prompt when the driver is missing, using the official signed installer.
- CPU voltage (VID) telemetry on supported Intel CPUs. CPU voltage replaces E-core frequency in the default overlay; unavailable voltage displays as 0.000 V. LibreHardwareMonitor is not used.
- Independent GPU Delta and Dynamic Boost controls in both Tuning and Games, using the calibrated NVIDIA default power limit as the baseline.
- Mandatory first-time factory calibration when OpenCore is active. Users can calibrate or uninstall OpenCore; completed defaults are protected against recalibration.
- In-place OpenCore/ACPI re-install and update notifications. Replaced files are backed up, copies are SHA256-verified, and the console stays open with a Y/N restart prompt.
- Automatic repair of stale PreySense WMI method definitions after confirming that the matching ACPI table is loaded.

## Fixes and interface improvements

- Fixed stale minimum-limit baseline metadata being reused as GPU baseline; the verified laptop uses the standard 85 W default, rather than the 5 W minimum.
- Preserved independent Delta and Dynamic Boost values in game profiles and fixed number-box bindings that could leave profile values out of sync.
- Fixed incomplete firmware reads being treated as completed calibration. Failures now identify unavailable mode/readback values instead of hiding them.
- Fixed custom limits being applied before calibration or while overrides were disabled, and improved reporting of failed CPU/GPU/thermal writes.
- Removed duplicate boost writes and redundant intermediate power-limit writes when launching game profiles.
- Changing the profile dropdown in Tuning now activates that mode.
- Tray menu follows the selected app theme.
- Simplified GPU labels, removed the manual ACPI-offset read buttons and descriptions, and tightened calibration dialog spacing.
- Factory summaries list Eco, Quiet, Balanced, Performance, and Turbo first, with GPU totals grouped as `GPU 130W [Delta 30W · Dynamic Boost 15W]`. Shared metrics follow without a separate heading.

## Upgrade notes

- This release requires ACPI interface **0x0201** for the new GPU controls. If prompted, use **Advanced → Re-install**, then restart through the PreySense/OpenCore boot entry.
- The GPU platform power offset is fixed at **255 W in ACPI** and is no longer managed by the app. It is an offset, not a guaranteed CPU + GPU wattage ceiling.
- Existing saved factory profiles remain protected. Stale WMI definitions are repaired automatically by the elevated app when the matching ACPI version is loaded.
- GPU reference wattages do not guarantee sustained GPU power. CPU voltage is VID; a zero display means the voltage read is unavailable.
- Windows 10/11 x64, administrator privileges, and the .NET 10 Windows Desktop Runtime are required.
