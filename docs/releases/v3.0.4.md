# PreySense v3.0.4

- Simplify show/hide behavior: opening brings PreySense forward; losing foreground focus hides it and clears always-on-top. Restore previously open tool windows when reopening.
- Improve tuning calibration, replace incomplete factory captures, and keep PROCHOT lock state and temperature labels consistent.
- Clarify JSON configuration names and documentation; accept the current configuration schema without migrating v1 files.
- Simplify CPU/GPU telemetry and overlay rendering, improve settings layout, localization, and native window styling.
- Expand automated coverage for calibration, tuning, configuration, and window visibility.

Requires Windows x64 and the .NET 10 Desktop Runtime.
