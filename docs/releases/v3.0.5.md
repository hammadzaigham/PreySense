# PreySense v3.0.5

- Keep lighting responsive by moving keyboard/cover hardware writes and saves to a serialized background worker. Rapid edits retain the latest pending values, and effect transitions wait for old animation frames to stop.
- Move blocking fan saves, startup-task operations, GPU process checks, CPU boost operations, and tuning readback off the UI thread. Preserve final lighting edits during shutdown.
- Restore USB power-off charging, disabled by default. Its slider uses 0 for Disabled and 10/20/30% battery cutoffs; unverified operations show N/A.
- Compact fan JSON by omitting unreachable trailing stages while retaining the terminal disabled-trip stage. Fix graph creation changing drafts and omitting a reachable final stage.
- Add JSON-only overlay colors, graph line width, corner radius, and background shading. Round overlay corners with transparent corner pixels.
- Show PreySense in the taskbar while visible and remove its taskbar entry when hidden.
- Fix Settings window initialization after the USB slider change. Report startup errors visibly and append details to the existing debug.log.
- Clarify tuning success as “Applied and read back successfully,” update translations and configuration documentation, and improve overlay selector spacing.

Requires Windows x64 and the .NET 10 Desktop Runtime. Older v1 configuration files are not migrated automatically.
