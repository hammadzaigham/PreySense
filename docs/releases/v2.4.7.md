# PreySense v2.4.7

## Highlights

- Added automatic update installation from the official GitHub release asset.
- Added a safe updater handoff that replaces and restarts PreySense after it exits.
- Replaced periodic game detection with event-driven foreground-window tracking and process-exit monitoring.
- Replaced periodic power-source checks with Acer power events where available.
- Removed idle telemetry polling when fan curves are automatic or the overlay is disabled.
- Disabled FPS/ETW monitoring, NVML overlay polling, overlay rendering, and overlay-specific CPU-frequency sampling when the overlay is off.
- Avoided repeated registry reads during mode checks by caching application configuration values.
- Avoided repeated profile application when the active game/profile has not changed.
- Reduced unnecessary WMI/EC reads and hardware writes by caching fan targets and only sending changed values.
- Kept HID key monitoring active for hardware controls while leaving Copilot key events ignored instead of treating them as Turbo.
- Deferred DTS audio initialization until it is actually used.
- Split overlay, WMI, ACPI, and OpenCore code into focused partial files for easier maintenance.
- Removed redundant tests and preserved existing HID/APGe/AcerGeneric event behavior.

The release is published as a self-contained `PreySense.exe` asset through the normal GitHub publishing workflow.
