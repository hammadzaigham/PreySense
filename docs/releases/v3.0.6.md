# PreySense v3.0.6

- Share one telemetry timer and one sample cycle across the main window, overlay, and Custom fans. Consumers request only the metrics they need; the timer stops when nothing is demanding sensors.
- Show CPU/GPU temperature and fan RPM on the main window while it is visible, and clear those readings when it is hidden.
- Fix Run on Startup: accept Task Scheduler’s normalized task XML, use an unscoped logon trigger with the enabling account as principal at HighestAvailable, and keep the Settings toggle from flipping off after a successful create.
- Harden lighting apply paths and telemetry demand handling, with additional coverage for overlay efficiency, shared demand, and main-window telemetry.
- Update configuration, fan, keyboard RGB, and telemetry documentation for the shared sampling model.

Requires Windows x64 and the .NET 10 Desktop Runtime. Older v1 configuration files are not migrated automatically.
