# PreySense v3.0.0

## Before you upgrade

1. Uninstall your previous PreySense version first. Do not copy v3 over an old install.
2. Run the new `PreySense.exe` as administrator.

## What's new

### Driver tuning

- Custom CPU and GPU power limits use the bundled CPU driver.
- Turn on **Enable Tuning**, edit a mode, then **Apply** or **Save**.
- Saved modes apply automatically on mode switch, startup, and wake when tuning is enabled.

### Per-mode power controls

For each Acer mode (Eco, Quiet, Balanced, Performance, Turbo):

- CPU **PL1**, **PL2**, and **Tau**
- GPU **Delta**, **Dynamic Boost**, and **platform power offset**

### Factory calibration

- Factory defaults are read once into `preysense.json`.
- **Reset** returns a mode to those captured values.
- Custom values stay null until you explicitly **Save**.

### PROCHOT offset

Optional global temperature offset under Enable Tuning. Apply/Save can write it with the rest of the profile when its switch is on.

### Overlay and clocks

- Overlay metrics are selectable.
- GPU Active and Effective clocks are separate choices.
- CPU requested voltage (VID) is available through the bundled driver.

### Removed in v3

- Legacy ACPI override path
- DTS audio windows
- Per-game profile launcher
- Older PawnIO-based CPU path

Core Predator features remain: modes, fans, lighting, display, battery, tray, languages.

## How to use tuning

1. Open **Tuning**.
2. Enable tuning.
3. Pick a mode and set values.
4. **Apply** to test, or **Save** to keep them.
5. Switch modes as usual; saved profiles follow the mode.

Verified on **Predator Helios Neo 16S (`PHN16S-71`)**. Other models may work.
