# PreySense v2.4.9

## Highlights

- **Shared Telemetry Coordinator:** Unified hardware telemetry sampling across MainWindow and HardwareOverlay with single-producer immutable snapshots, demand-driven sampling cadences, and independent background fan safety monitoring.
- **Event-Driven Display & DDS Architecture:** Replaced periodic 1 Hz polling of display refresh rate (`EnumDisplaySettings`) and NVIDIA DDS status (`NvCplApiGetInfo`) with an event-driven system hooked to `SystemEvents.DisplaySettingsChanged` and power events, eliminating background GPU wakeups and failed API calls during D3 Cold sleep.
- **WMI Event Listener Quota Resolution:** Unified hotkey and power-source ACPI event listening on `APGeEvent` through a single subscriber, eliminating ACPI WMI driver `Quota violation` (0x8004106C) conflicts.
- **Preset Theme Persistence:** Resolved an issue where preset keyboard lighting themes (e.g. Fire & Ice, Matrix, Cyberpunk) reverted to "Custom" on application restart or when opening the Keyboard window.
- **RGB Startup Reliability:** Hardened HID RGB feature report transmission with self-healing handles and reinforced 2-pass startup lighting to guarantee settings persist across cold boots.
- **GPU Mode UI & Layout Polish:** Formatted Advanced Optimus active display mode as `"dGPU"` (reserving `"dGPU exclusive"` strictly for hardware BIOS MUX mode), and made GPU mode tiles dynamically expand to fill the full grid width when the iGPU tile is collapsed in Advanced Optimus.
- **UI & Telemetry Polish:** Restored distinct per-metric freshness tracking and per-logical-core peak utilization accuracy.
