# PreySense v3.0.1

## Fixes

- **PHN16-71 hardware tuning** — ERM4 base is discovered from the live DSDT / `"Predator"` signature probe (`0xFE708400` on BIOS V1.20), not hardcoded to `0xFE800400`. MCHBAR accepts Raptor Lake host bridges including `463B` and `4637`, not only `7D1C`.
- **Custom/Max fans at startup** — retries early OEM WMI write races and re-applies Max/Custom curves once after startup settle. Auto is unchanged.
- **CPU Boost** — Tuning editor uses a Windows PERFBOOSTMODE dropdown (Disabled through Efficient Aggressive At Guaranteed) instead of an on/off switch. Default remains Enabled.

## Driver rename

- Bundled driver file/service is now `PreySenseDriver` (payload bytes unchanged from v3.0.0).
- ThrottleStop naming removed from app source.

## Notes

- Still verified primarily on **PHN16S-71**. PHN16-71 support needs on-device confirmation for ERM4/MCHBAR.
- Uninstall previous PreySense before upgrading when moving major versions; v3.0.1 is a normal app update over v3.0.0.
