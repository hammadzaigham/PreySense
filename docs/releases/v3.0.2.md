# PreySense v3.0.2

## Fan control

- Custom curves use EC-style **stages** (rise trips + RPM targets) instead of a fixed 5°C grid.
- CPU/GPU graphs are **temperature thresholds**; both fans run at the **higher** stage duty.
- Shared per-mode **Fan Control Delay** (0–5 s) holds stage changes for both fans.
- Retreat uses the previous stage’s rise (no separate fall trip in the editor).
- Stage temps must be unique; last filler stage is omitted from the graph (flat lead-out).
- Fan max RPM targets aligned to **6400**.

## Tuning

- Tuning header shows live **PROCHOT** activation temp and package **TjMax**.
- GPU **Delta** ceiling raised to **100 W** (5 W steps).

## Other

- Battery charge limit defaults to **on** (80%).
- Removed unused `LcdOverdrive`, `BlueLightShieldMode`, `UsbChargingPercent`, and `GpuBatteryAuto` config keys.
- Fixed Tuning crash from an invalid `ThumbShadow` effect target.
- Docs and schema updated for stages, delay, and the higher delta limit.
