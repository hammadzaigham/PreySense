# PreySense v3.1.1

## Responsiveness and size

- Move fan-setting, metrics and tuning persistence off the UI thread, combining pending edits.
- Avoid full configuration cloning while dragging fan curve points.
- Await in-flight mode operations before hardware shutdown.
- Compress embedded keyboard layouts without removing device support, reducing the executable by roughly 350 KB.

## Fans

- New/reset Custom curves start at zero cooling boost; existing saved curves are preserved.
- Replace Fan Control Delay with immediate increases and 3°C cooling hysteresis.
- Show one rounded estimated RPM value using the bundled PHN16S-71 reference; successful Max-mode calibration supplies each fan's maximum.
- Simplify the editor, separate measured RPM from estimates, and center fan readings.
- Profile selection never switches performance modes. Save/Reset affect hardware only for an active profile. Auto/Max choices save directly, with no footer buttons.
- Calibrate fans in hardware Max, outside the Custom follower.

## Compatibility and settings

- Add documented Core Ultra 200HX host-bridge IDs and MCHBAR address decoding.
- Add LCD Overdrive in Settings, enabled only after supported firmware readback; verify writes. This checks firmware state, not pixel response.
- Rename Game Mode to Game Profiles, move enabled switches into game rows, and use themed border-only selection.

RPM estimates remain approximate and do not read a user's firmware. No firmware is flashed or modified.
