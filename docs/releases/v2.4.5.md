PreySense v2.4.5

## New features

- **Interactive Fan Curve Editor**: Added a dedicated fan curve modal window accessible from the main dashboard with independent CPU and GPU fan curve controls.
- **WPF Telemetry Graph**: Custom, hardware-accelerated fan curve graph plotting 13 temperature points from 40°C to 100°C (in 5°C steps) with live cooling temperature indicators, live fan duty line, and intersection tracking.
- **Factory Fan Stage Presets**: Extracted and normalized factory fan RPM stages from Acer EC firmware (ZBJ-KQ EC 1.08) for Turbo, Performance, Balanced, Quiet, and Eco modes.
- **Fan Ramp-Up Delay**: Configurable 0–5 second response delay for fan duty changes to eliminate annoying fan revving and hunting during short bursts.
- **Emergency Cooling Safety**: Hardware-level safety override that immediately forces fans to 100% max cooling if CPU temperature reaches ≥ 95°C or GPU reaches ≥ 87°C until temperatures safely clear recovery margins (90°C CPU / 82°C GPU).
- **Smooth Mode Switching**: Selecting Auto or Max immediately applies and saves the fan mode to hardware without extra clicks. The curve graph remains visible in Auto and Max modes in a dimmed/disabled state.
- **Deselection & Keyboard Navigation**: Arrow keys and mouse drag for adjusting points; points start unselected and can be deselected by clicking empty space or pressing Escape.
- **Factory Reset**: Dedicated Reset action restores curves to factory defaults and resets fan control mode to Auto.

## Fixes and stability improvements

- **Game Profile Exit Synchronization**: Fixed an issue where exiting a game would fail to reapply the original mode's power and fan limits when the previous profile mode had the same name.
- **Power Source Transition Locking**: Serialized power source transitions (AC / Battery / USB-C) and game profile switches within the mode-switch gate lock, preventing race conditions.
- **Mode Switch Debounce Cancellation**: Changing power source or switching modes cancels pending debounce timers immediately to prevent outdated settings from applying late.
- **Zero Background Overhead**: Telemetry update timers and visual controls stop and are destroyed completely when the fan curve window is closed.
- **WMI Fan Command Reliability**: Cleaned up WMI fan mode commands (`SetFanModeAuto`, `SetFanModeMax`, `SetFanSpeedPercentage`) and unified duty percentage calculation.

## Upgrade notes

- Windows 10/11 x64, administrator privileges, and the .NET 10 Windows Desktop Runtime are required.
- If using OpenCore ACPI features, ACPI interface **0x0201** is maintained from v2.4.0.
